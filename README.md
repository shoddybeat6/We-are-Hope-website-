# We Are Hope

A responsive website for We Are Hope, a community-focused organisation in South Africa. The site introduces the organisation and its work, and provides pages for projects, volunteering, donations, and contact information.

## Website

[Visit the deployed site](https://we-are-hope.netlify.app)

> The Netlify project was marked private the last time it was checked. If the site is still private, change its visibility in Netlify before sharing the link publicly.

## Pages

- Home
- About Us
- Projects
- Volunteer
- Donate
- Gallery
- Contact

## Features

- Responsive layout designed for desktop, tablet, and mobile screens
- Navigation links between the site pages
- Clickable logo that returns to the home page
- Consistent footer with quick links and contact information
- Contact, volunteer, and donation forms with on-page responses

## Important notes about the forms

The forms are front-end demonstrations only. They do **not** send or store messages or applications, and the donation form does **not** process payments.

The donation page contains example banking details. Confirm and replace these with the organisation's correct details before asking anyone to make a donation.
