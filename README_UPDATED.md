Version 1 – we_are_hope.zip

The first version of the We Are Hope website consisted mainly of static content. The website included basic titles, text, images, navigation, and static cards for displaying information about the organisation and its projects.

The cards and other elements had limited interaction, which made the website simple but less engaging for users.

Version 2 – we_are_hopev2.zip

In Version 2, the website was improved through updates to the CSS stylesheet. The main purpose of these changes was to make the website more interactive and visually appealing.

The CSS update introduced features such as:

Hover effects on cards.
Hover effects on navigation links.
Interactive buttons.
Focus effects on form fields.
Active states for buttons and links.
Improved spacing and layout.
Rounded corners and shadows on cards.
Responsive layouts for smaller screens.
Improved gallery styling.
Better typography and visual consistency.

These changes allow elements on the website to respond when the user interacts with them. For example, project cards can change their appearance when the user moves the mouse over them, while buttons and navigation links provide visual feedback.

Summary

The transition from Version 1 to Version 2 improved the overall user experience of the We Are Hope website. Version 1 focused mainly on presenting static information, while Version 2 used CSS styling and interactive effects to make the website more engaging and responsive.

The updated CSS also supports the requirements for responsive design, allowing the website layout to adjust for desktop, tablet, and mobile screen sizes.
